## Platform

web

## Users
Operations leads and small teams who automate hand-offs between SaaS tools (onboarding, alerts, CRM updates) and want to see each run's state at a glance.

## Product Purpose
AuraFlow: landing page, login/register, and a dashboard with overview, workflows (list and runs), templates, scheduler, analytics, integrations, team and settings. React 19 + Vite with plain CSS (`src/index.css`); FastAPI backend.

## Positioning
Describe the automation in plain English; AuraFlow builds and runs it.

## Capabilities and Constraints
- One global stylesheet with CSS variables; JSX uses class names and some inline SVG colours.
- Landing stats, testimonials, "500+ apps", prices and the version badge are marketing placeholders.

## Brand Commitments
- Name "AuraFlow".

## Product Principles
1. Show the flow: steps happen in an order you can read.
2. Every run has a visible state.
3. Plain language.
